1. Наш стек:
- C# / .NET 10 — управляющий сервер, агенты VPN-нод и логика приложений.
- Avalonia UI — собственные клиенты для Windows, Linux, macOS, Android и iOS.
- MySQL — база данных.
- Telegram ID — регистрация и вход через бота; клиент получает сессию по одноразовой ссылке из Telegram.
- AmneziaWG — туннель между устройством и выбранной VPN-нодой; подключаем через платформенные обертки.

2. Перед каждым методом C# независимо от модификатора доступа необходимо добавлять краткую XML-документацию на русском языке в формате `/// <summary>...</summary>`, описывающую назначение метода.
